# Pharmacy Management App

A simple pharmacy inventory management application built with Android Studio.

## About

This is a basic Android application for managing pharmacy inventory. It allows users to add, view, update, and delete medicine records. The app demonstrates fundamental Android development concepts including database operations and user interface design.

## Features

- Add new medicines to inventory
- View list of all medicines
- Update medicine details and quantities
- Delete medicines from inventory
- Search for medicines by name
